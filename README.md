🎮 Juego de Plataformas 2D

Un juego de plataformas 2D creado en Scratch y actualmente en desarrollo.

🕹️ Sobre el juego

En este proyecto podrás explorar diferentes niveles, superar obstáculos, enfrentarte a enemigos y descubrir nuevos desafíos.

El juego irá creciendo poco a poco con nuevas mecánicas, niveles, personajes y contenido.

✨ Características
🏃 Movimiento del jugador
🦘 Saltos y plataformas
👾 Enemigos
🗺️ Diferentes niveles
💎 Coleccionables
🎵 Música y efectos de sonido
🚧 Nuevas funciones en desarrollo
📦 Proyecto

El proyecto principal está desarrollado en Scratch y se guarda como un archivo .sb3.

🚧 Estado

En desarrollo 🛠️

Actualmente el juego se encuentra en una etapa inicial y todavía recibirá muchas mejoras.
